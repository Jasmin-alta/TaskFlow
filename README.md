# TaskFlow — Task Management System

TaskFlow is a client-side task management web application built with HTML, CSS, and JavaScript. It allows users to organize daily tasks through an interactive interface, with browser-based storage to save their progress.

# Features

Task Creation: Add new tasks dynamically.

Task Completion: Mark tasks as completed to track progress.

Task Deletion: Remove tasks from the list.

Local Storage: Persist tasks and completion statuses across browser sessions.

# Technologies Used

HTML5 — Structures the application.

CSS3 — Styles the user interface.

JavaScript — Implements task management functionality, DOM manipulation, and event handling.

localStorage API — Stores task data in the browser.

# How It Works

TaskFlow uses JavaScript event listeners to handle user interactions and DOM manipulation to update the interface without page reloads. Task data is saved using localStorage, allowing users to retain their tasks after refreshing the browser.
